# Appfw Standards

* [Appfw-File-Standards](Appfw-File-Standards/) - File management standards for upload, download, and storage operations
* [Appfw-Interface-Standards](Appfw-Interface-Standards/) - Interface and batch processing standards
* [Appfw-Logging-Standards](Appfw-Logging-Standards/) - Structured logging standards and log schema conventions
* [Appfw-Mcc-Standards](Appfw-Mcc-Standards/) - MCC platform services standards (MCNS, MPDS, shared auth)
* [Appfw-Mfa-Standards](Appfw-Mfa-Standards/) - Multi-factor authentication standards (PIN, TOTP, critical transaction)
* [Appfw-Report-Standards](Appfw-Report-Standards/) - Report generation standards (core and programmatic)
* [Appfw-User-Standards](Appfw-User-Standards/) - User access control and authentication standards
