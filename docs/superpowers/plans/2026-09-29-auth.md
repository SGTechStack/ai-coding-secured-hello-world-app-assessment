# Secured Hello World Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task by task.

**Goal:** Complete and push all PRD stories on jingshun with meaningful security tests.
**Architecture:** React SPA calls a Spring REST API using CSRF-protected JDBC sessions.
**Tech Stack:** Java 21, Spring Boot/Security/JPA/Session, H2, React, TypeScript, Vite.
**Spec:** `prd/assessment-prd.md` and `docs/superpowers/specs/2026-09-29-auth-design.md`.

## Global constraints

All twelve PRD stories and its minimum integration coverage are mandatory.
BCrypt, HttpOnly sessions, CSRF on every mutation, exact credentialed CORS, generic
login/reset-request errors, structured audits, and server role checks are mandatory.
JWT, SMTP, containers, CI/CD, and local TLS are outside scope.

## Review focus

1. Concurrent reset redemption must not succeed twice (task 2 integration test).
2. A stale admin session must not retain privileges after demotion (task 2 test).
3. Login/logout must rotate CSRF/session state without breaking the SPA (tasks 1, 3).
4. Unicode password byte limits must not allow BCrypt truncation (task 1 test).
5. IP throttling must not let one source lock a victim account (task 1 test).

## Task 1: Authentication and persistence

Files: `backend/pom.xml`, Maven wrapper, `backend/src/main/java/com/example/hello/`,
`backend/src/main/resources/`, `backend/src/test/java/com/example/hello/AuthIntegrationTest.java`.
Produces registration/login/logout/me/hello/csrf per design API, User DTO, repositories,
password policy, audit log, session invalidation, and bootstrap service.

- [ ] Scaffold reproducible build; write real HTTP tests for registration, generic
  credential errors, account/IP lockout, expiry recovery, CSRF, CORS, cookie flags,
  session fixation/logout replay, bootstrap and UTF-8 password policy.
- [ ] Run tests against absent routes and observe expected failures.
- [ ] Implement security chain, JPA persistence, auth services, and controllers.
- [ ] Run `backend/mvnw.cmd verify`; resolve actual failures; conventional commit.

## Task 2: Reset and admin
