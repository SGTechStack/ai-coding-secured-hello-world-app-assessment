#### How to use this template

1. **Copy this file** into the `Field-notes ({{track}})` folder (e.g. rename to `Operator-session-2026-05-22.md`).
2. **Rename your copy** to something memorable — e.g. `Operator-session-2026-05-22.md`. Use whatever scheme suits you; CLARA reads the body, not the title.
    - Drop the `_Template — ` prefix.
    - Drop the `({{track}})` suffix too.
3. **Leave Session ID blank.** CLARA stamps it the first time she processes the note; do not edit this field yourself.
4. **Fill in the rest.** Participants, User group, Date, and Conducted by are metadata; Raw notes and Verbatim quotes are the substance.
5. Delete this *How to use* block before saving — it's guidance for you, not part of the note.
