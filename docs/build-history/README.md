# Build history

Working material from building this app with AI coding agents. None of it is needed to run or test the app; it is kept
as evidence of how the build was planned, executed and reviewed.

- `planning/`: the planning stage: the build map, research, ADR routing, the deferral register, the test-plan
  transcription and throwaway prototypes that fed `docs/spec.md`, `docs/adr/` and `docs/test-plan/`.
- `build/issues/`: the implementation tickets (01–34), each with its acceptance checklist, status and closeout notes.
- `build/orchestration/`: the orchestrator's handover and the common brief every ticket agent followed, including the
  gate rules.
- `build/orchestration/reviews/`: independent review reports from the review-fix wave.

Per-ticket code-review compliance reports are in `docs/reviews/compliance/`.
