# Triage labels

Skills talk about five triage roles. This repo uses the same strings on GitHub.

| Role the skill uses | Label in this repo | When to apply it |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Someone still has to decide whether the issue is in scope |
| `needs-info` | `needs-info` | The report is missing a step, account, or expected response |
| `ready-for-agent` | `ready-for-agent` | The spec is enough for an agent to implement |
| `ready-for-human` | `ready-for-human` | A person needs to make the change |
| `wontfix` | `wontfix` | The issue will not be done |

When a skill says "apply the AFK-ready label", add `ready-for-agent`.
